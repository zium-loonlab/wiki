Android는 APK 파일을, iOS는 TestFlight 초대 이메일을 발송해드립니다.

02 · 설치 방법

내 기기에 맞게 설치하세요

승인 후 기기에 맞는 파일 또는 초대 링크를 이메일로 발송드립니다.

Android
APK
⚠️
설치 전 설정 필요
설정 → 보안 → 알 수 없는 앱 허용을 켜주세요.
APK는 Play Store 외부 설치 파일입니다.
  1. APK 파일 수신 — 이메일로 발송된 APK 파일을 다운로드합니다.
  2. 알 수 없는 앱 허용 — 설정 → 보안에서 허용으로 변경합니다.
  3. 파일 실행 → 설치 — 다운로드 폴더에서 파일을 열어 설치합니다.
  4. 알로까 시작! — 설치 후 앱을 실행하고 피드백을 남겨주세요.
iOS
TestFlight
  1. TestFlight 설치 — App Store에서 TestFlight를 검색해 무료로 설치합니다.
  2. 초대 이메일 확인 — 승인 후 24시간 내 Apple ID 이메일로 초대 링크가 발송됩니다. 스팸함도 확인해주세요.
  3. 링크 클릭 → 설치 — 이메일의 "Start Testing" 버튼을 iPhone에서 클릭합니다.
  4. 알로까 시작! — TestFlight 앱에서 설치 후 실행하고 피드백을 남겨주세요.
